Now

AI Engineer at Medevio since 2026

Medevio is a patient–doctor communication platform. I own the AI inside it, from prompt to rollout.

  • AI features in production: drafted replies for doctors, request summaries in Czech and Slovak, call and SMS processing, meeting transcription.
  • Agent-first delivery across the team’s repositories: conventions, skills and executable runbooks that coding agents work against — with scoped credentials, so an agent can run a data job but never touch a live clinic.
  • Evaluation as the deciding step: LLM judges, holdout sets and significance tests. A change ships when the measurement says it helped, and gets killed when it doesn’t.
  • Production TypeScript — Bun, Fastify, PostgreSQL — on AWS with Terraform and GitLab CI.

A real-estate watchdog that reads the ad text.

Scrapes four Czech property portals, normalises ads into PostgreSQL and extracts with an LLM what portals don’t categorise — pets allowed, no commission, brick or panel. kviff.ai

seasonal

An AI guide to the Karlovy Vary film festival.

Crawls the festival programme, enriches films from TMDB, OMDB and ČSFD, embeds them and answers in chat: what to see tonight, what fits between two screenings, how far the venues are from each other. Per-user and global token budgets keep the bill predictable.

Runs during the festival in July; hibernated between editions.
