AI inženýr v Medeviu od roku 2026

Medevio je platforma pro komunikaci mezi pacientem a lékařem. Mám na starosti AI, která v ní běží — od promptu po nasazení.

  • AI funkce v produkci: návrhy odpovědí pro lékaře, shrnutí požadavků česky i slovensky, zpracování hovorů a SMS, přepis schůzek.
  • Agent-first vývoj napříč repozitáři týmu: konvence, skilly a spustitelné runbooky, proti kterým kódovací agenti pracují — s omezenými přístupy, takže agent může spustit datovou úlohu, ale nikdy nesáhne na ostrou ordinaci.
  • Vyhodnocení jako rozhodující krok: LLM soudci, holdout sady, testy významnosti. Změna jde ven, když měření ukáže, že pomohla — a končí, když ne.
  • Produkční TypeScript — Bun, Fastify, PostgreSQL — na AWS s Terraformem a GitLab CI.

Realiterier

běží, scraper stojí

Hlídací pes na reality, který čte text inzerátu.

Stahuje inzeráty ze čtyř českých realitních portálů, normalizuje je do PostgreSQL a pomocí LLM vytahuje to, co portály nekategorizují — zvířata povolena, bez provize, cihla nebo panel. Slučuje stejný byt napříč portály, označuje podvodné vzorce a do pár minut posílá e-mailem odpovídající inzeráty. Předplacení hlídači přes Stripe.

Web běží na Pi; scraper a placená API jsou vypnuté, nové inzeráty zatím nepřitékají.
